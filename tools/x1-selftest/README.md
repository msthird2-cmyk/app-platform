# @tools/x1-selftest

The X-1 runtime self-test. **Not a product and not shipped** — it exists to be
built by CI, run once on an Android emulator, and thrown away.

## Why it exists

`packages/security` has two `CryptoService` implementations. `WebCryptoService`
delegates to WebCrypto; `PortableCryptoService` implements the same envelope in
pure JavaScript for React Native, which has no WebCrypto.

The host test suite proves the portable path is correct under Node and V8.
Hermes is a different engine, with its own typed-array and 32-bit arithmetic
implementation. A divergence there would not throw — it would produce different
bytes, and that surfaces much later as a backup that will not open. Only running
on the real engine rules it out.

## What it checks

On the device, with `crypto`, `btoa`, `atob`, `TextEncoder` and `TextDecoder`
deleted from the global object *before* `@platform/security` is imported:

- the engine really is Hermes (the run fails immediately if not)
- `expo-crypto` returns entropy across the native bridge
- the `@platform/security` module graph evaluates at all
- AES-256-GCM round trip, including non-ASCII plaintext and passphrase
- tampered ciphertext, wrong key, and wrong AAD (both user and application) are rejected
- PBKDF2 `hashSecret` / `verifySecret`
- recovery-code generation, hashing and verification using the injected entropy
- `createCryptoService` returns `PortableCryptoService` when WebCrypto is absent
- PBKDF2 at the **shipped** iteration count, timed and printed

The iteration count is deliberately not lowered. The number it prints is the one
a user actually waits for.

## Running it

In CI: `.github/workflows/android-runtime.yml`, on every change to
`packages/security` or to this directory.

By hand, against a connected device or a running emulator:

```sh
pnpm install
pnpm turbo build --filter @platform/security...
cd tools/x1-selftest
npx expo prebuild --platform android --no-install
npx expo run:android --variant release
adb logcat | grep -E 'X1-SELFTEST|X1\|'
```

The results also render on screen, so a human running it by hand does not need
logcat.

## Boundaries

Nothing in `apps/` or `packages/` may depend on this directory. It imports
`@platform/security` and nothing else from the workspace, and it adds no
capability to any application. `android/` and `ios/` are generated by
`expo prebuild` and are gitignored.
